# MEMORI

> Your gallery remembers everything. MEMORI helps you remember what matters.

MEMORI is an AI-powered digital memory platform that automatically syncs photos and videos from Android, organizes them into meaningful memories, and helps users search, explore, and relive their moments.


## ✨ Features

- 📱 Automatic Android Gallery Sync
- 🧠 AI Memory & Event Detection
- 📂 Event + Year Organization
- 🔎 Natural-Language Memory Search
- 🎞️ Interactive Memory Albums
- ▶️ Relive Mode
- ✍️ AI Memory Stories
- 🔄 Memory Rediscovery
- 🧹 Smart Gallery Cleanup

## 🛠️ Tech Stack

- **Android:** Kotlin, Android SDK, MediaStore, WorkManager, Retrofit
- **Backend:** Java, Spring Boot, Spring Security, JWT, JPA, Hibernate
- **AI:** Python, FastAPI, OpenCV, Embeddings, Semantic Search
- **Database:** PostgreSQL, pgvector
- **Web:** Lovable, React
- **Tools:** Git, GitHub, Postman, pgAdmin, Android Studio, Eclipse, VS Code

## 🏗️ Architecture

```text
Android App ──┐
```
